## The pitch

> A pen that, when it runs out of ink halfway through your signature, forges the rest of it in handwriting slightly worse than your own.

## How it works

`main.ts` (Node 22, standard library only, no network, no clock, no randomness)
writes the single-sentence pitch to `/output/entry.txt`. The output is fully
deterministic: every run produces the exact same bytes.

Run it with:

```sh
node main.ts
```
